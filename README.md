# 👗 FashionStore

FashionStore is a full-stack Java web application for online fashion shopping.  
Users can browse products, view product details, add items to cart, and place orders.

---

# ✨ Features

## 👤 User Module
- User Registration
- User Login
- Session Management
- Logout

## 🛍 Product Module
- View Products
- Product Details Page
- Product Variants (Sizes)

## 🛒 Cart Module
- Add to Cart
- Update Quantity
- Remove Item
- View Total Price

## 📦 Order Module
- Checkout Page
- Place Order
- Delivery Details

# 🚀 How to Run the Project

## 1️⃣ Clone Repository

```bash
git clone https://github.com/James052024/FashionStore.git
```

---

## 2️⃣ Import Project

- Open Eclipse
- File → Import
- Existing Maven Project
- Select FashionStore folder

---

## 3️⃣ Configure Database

Create database in MySQL:

```sql
CREATE DATABASE fashion_store;
```

Import:

```text
fashion_store.sql
```

---

## 4️⃣ Configure Tomcat Server

- Add Apache Tomcat in Eclipse
- Run project on server
